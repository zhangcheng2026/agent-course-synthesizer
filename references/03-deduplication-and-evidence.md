# 03｜证据去重与教学去重：删重复，不删理解过程

## 证据去重

比较命题、前提、适用场景、技术版本和指标分母后才合并。原文、译文、迁移副本、同一作者的延伸笔记不可计为多个独立证据。个人理解或 Skill 自拟解释不能冒充作者原话。对有冲突、独有机制、不同框架的材料分别标注限定，不能强行统一。

## 教学去重

v0.2 的“一个概念只完整解释一次”继续有效，但**不能把“为什么、怎么做、实际例子、反例”误判为多余文字**。同一个知识点：

- 重复定义、同一个结论换词说、反复复制相同流程图 → 合并或删除。
- 原先容易失败的场景、机制推导的关键步骤、反向示例、为什么选择/不选择该技术 → 保留，因它们回答不同问题。
- 同一案例在多个章节出现，如果每次承担不同功能（第一次建立问题、第二次暴露边界、第三次验证），可保留必要片段并用引用衔接，不必每次重述整个案例。
- 用户明确要“深度学习”时，不能为迎合摘要长度删掉重要说明。深度正文和精炼复习分别优化。

每段自检：它是否帮助读者**从原因走到结论**？是否解释了一个新步骤、易错点、不同反馈或工程判断？删掉会不会让初学者只知其然而不知其所以然？如果是，就应保留或合并进正确的位置。

研究记录保留来源表与 `claim_matrix`；教学正文引用关键来源但不倒灌全文。Notion 私有资料不得复制进公开 GitHub。没有真实运行的示例不能假装模型实验，模拟样本要标注为教学构造。
