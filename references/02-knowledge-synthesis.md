# 02｜跨课知识综合

用“要解决什么问题”而不是“哪个老师说”来聚类。每个主题记录 theme_statement、Claim IDs、来源独立组数、适用条件、so_what（为什么学）、next_step（如何验证）及教学正文位置。

六种关系：SAME（条件相同的同义主张）、COMPLEMENTARY（机制互补）、CONFLICT（同条件结论冲突）、UNIQUE（单来源重要内容）、EVOLVED（有证据的版本演进）、UNCERTAIN（来源不足或不可核实）。不制造不存在的冲突；不因出现多次就把结论当成事实。

研究矩阵列：Concept｜综合结论｜Claim IDs｜关系｜去相关来源数｜分歧/版本/限定｜正文落点。**教学正文不展示整张长表**，而是按一个贯穿的因果链组织真实有用的知识。ReAct、Tool Calling、Agent Loop 不能因为表述相似而错误合并；框架 API 不能升格为普遍定义。
