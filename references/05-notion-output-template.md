# 05｜Notion 双层课程输出模板

## A. Step 教学正文（面向学习）

页面 Title 设置在 Notion 属性里，正文不要再复制同一大标题。顺序建议：核心结论和目标 → 贯穿案例 → 横向流程与反馈分支 → 按案例引入 Model/Harness/Context/Tool 等必要概念 → Workflow 与 Agent 取舍 → 最小实践 → 结论/复习/短来源入口。

首次术语采用“中文（English）”；API/代码名保持原名。以少量紧凑段落为主，不用一句一段、密集表格或目录式罗列。学术限定条件必须保留，但核心知识只在一处完整解释。正文重要主张附 Notion 精确章节链接；文末简短指向完整研究记录。

## B. Research Record（独立关联页）

包含 source_manifest、Atomic Claims、claim_matrix、去相关来源数量、冲突/独有/待核查项、概念依赖、审计及发布状态。默认与 Step 同层或作为 Step 子页，不把全部长表附在正文尾部。对于要替换现有 Step 的情况，先有可回读原稿快照，正文保留研究页与快照入口。

代码标注“伪代码 / mock / 真正运行”，列出输入、依赖、执行方法、预期和实际验证状态；不能把 mock 推理称为真实 LLM 运行。
