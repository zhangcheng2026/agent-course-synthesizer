# 05｜中文 Step 课程输出模板

## 标准笔记体例

```markdown
# Step N｜课程主题
> 版本 / 整合日期 / 来源范围 / 覆盖状态（全量或抽样）

## 本节学习目标
用 2–4 句明确可检查的目标，不写空泛口号。

## 核心结论
以 1–2 段说明核心模型和核心误区；关键主张标出处。

## 机制与架构
一条横向主链 + 必需的辅助分支，说明输入、输出、条件与数据边界。

## 关键知识点
按逻辑分小标题；定义→机制→举例→局限；不按课程作者逐个展开。

## 进阶方案与工程权衡
逐项说明适用范围、代价、失败案例、何时不使用。

## 最小案例
用真实课程示例改写为统一案例；涉及特定框架时标注来源和版本。

## 评估与常见误区
指标定义、具体检查方法、风险、术语混淆。

## 本节复习
核心概念清单和 3–5 个问题。不是重复一遍全文。

## 来源
课程名 + 精确章节 / 页面链接 / 补充外部核验（若有）。

## 课程整合审计（可折叠或独立页）
独有观点、冲突、缺页、置信度、待补证据。
```

## 写作规范

- 简体中文、紧凑分段、每段围绕一个完整意思；大标题少而有效，避免一句一段。
- 术语首次用“中文（English）”；代码 API 原名不翻译；避免把通俗比喻冒充技术定义。
- 来源链接放在关键论述之后；不需要每句话重复长 URL，但每个核心知识主张必须能定位。
- 图示优先横向：`文档→切分→索引→检索→上下文→生成`；涉及高风险/例外可另加分支。
- 以“结论、框架、概念、必要细节”为主，默认不复制课程的完整论述过程；关键例子与限定条件不可删。
- 可选“课程作者说法／本 Skill 综合／外部补充”三区分，防止来源混淆。
